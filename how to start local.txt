How to start local:

Step 1: Install all required dependencies
        > cd backend
        > pip install -r requirements.txt  
        
Step 2: Update yt-dlp to the latest version
        > pip install -U yt-dlp
        
Step 3: Make sure your React frontend is built (do this once or when you modify the frontend)
        > cd ../frontend
        > npm install
        > npm run build
        
Step 4: Run the Native Desktop Application
        > cd ../backend
        > python main.py
        
        The app will automatically launch in a native desktop window.
