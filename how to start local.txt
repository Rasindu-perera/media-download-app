how to start local:

step 01:  Install all required dependencies:
          \media download app\backend> pip install -r requirements.txt  

step 02:  Update yt-dlp to the latest version:
          \media download app\backend> pip install -U yt-dlp

step 03:  \media download app\backend> python -m uvicorn main:app --reload  (start this backend server)

step 04:  \media download app\frontend> npm start (start this frontend server)

step 05:  Open your browser and navigate to `http://localhost:3000`
